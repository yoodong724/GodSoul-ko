GODSOUL 한글 패치

1. 적용 대상 Steam 빌드

Steam 빌드 26991245 / Steam App 1213300
게임 내부 버전 1.99
배포 파일 godsoul-ko-26991245.zip
지원 환경: Windows 11, 기본 Windows PowerShell 5.1.
별도 Python 설치나 실행 중 다운로드는 필요 없습니다. 안내 창은 영어입니다.
드라이브 문자가 있는 로컬 설치 경로만 지원합니다. 네트워크·WSL 경로는
지원하지 않으며, 경로가 너무 길면 짧은 경로로 옮겨야 합니다.
설치기는 원본 Pak과 실행 파일 두 개의 SHA-256으로 지원 빌드를 확인합니다.
대상 파일이 다르거나 게임이 업데이트되면 설치가 거부될 수 있습니다.

2. 마지막 릴리스 이후 업데이트 내역

1.99의 새 게임 내 공지와 손패가 필요할 때 표시되는 스킬 안내를 번역했습니다.
2장 대사 7개를 바뀐 원문에 맞추고 1.98 RC1의 휴대전화 스티커 기록 수정을 이어받았습니다.
설치는 KoreanPatch\install.cmd, 제거는 restore.cmd를 사용합니다.
실게임 확인 범위와 보류 항목은 yoodong724/GodSoul-ko의 배포 릴리스에 있습니다.

3. 설치 방법

1) 게임, 런처 업데이트, 모드 관리자 등 게임 파일을 바꿀 수 있는 프로그램을
   모두 종료합니다. 필요하면 세이브를 별도로 백업하세요.
2) 예전에 수동 설치한 GODSOUL\Content\Paks\GodSoul-Windows_0_P.pak이 있으면
   기존 수동 설치 파일을 먼저 지우세요. 보관하려면 게임 폴더 밖으로 복사한 뒤
   지우세요. 같은 파일이라도 남아 있으면 새 설치기는 덮어쓰지 않고 거부합니다.
   원본 GodSoul-Windows.pak은 삭제하거나 교체하지 마세요.
   다른 한글 Pak·모드와의 중첩은 지원하지 않습니다.
3) ZIP의 KoreanPatch 폴더를 게임 설치 폴더 안에 넣습니다.
   GodSoul.exe와 KoreanPatch 폴더가 같은 위치여야 합니다.
4) KoreanPatch\install.cmd를 실행하고 경고를 읽은 뒤 Y로 확인합니다.
   완료될 때까지 창을 닫거나 컴퓨터를 끄지 마세요.
5) 한국어는 게임의 일본어 슬롯을 대신 사용합니다. 게임 설정의 언어에서
   일본어(중국어 화면에서는 '日文')를 고르면 한국어가 나오고, 그 뒤로는
   언어 목록에 '한국어'로 표시됩니다. 패치를 설치한 동안에는 원래
   일본어를 쓸 수 없습니다. 언어를 바꾼 뒤 게임을 완전히 종료하고
   다시 실행하세요.

제거·복구와 업데이트:
- 게임과 파일 변경 프로그램을 종료한 뒤 KoreanPatch\restore.cmd를 실행하고
  Y로 확인합니다. 이 설치가 추가한 Pak을 제거하고 설치 기록·백업을 정리합니다.
- 복구 전에는 KoreanPatch의 backup·state를 직접 지우지 마세요.
- 이전 KoreanPatch 버전은 그 버전의 restore.cmd로 먼저 복구한 뒤 새 ZIP을
  배치하세요. 수동 설치본은 위 2)의 방법으로 먼저 제거해야 합니다.
- Steam 업데이트 전에 복구하세요. 업데이트 후에는 해당 빌드용 패치를 쓰세요.
- 작업 중단이나 충돌이 보고되면 로그를 확인하고 임의로 상태·백업을 지우지
  마세요. 재실행으로 처리되지 않으면 패치 Pak을 게임 폴더 밖에 보관하여
  비활성화한 뒤 Steam 파일 검사 또는 게임 재설치로 원본을 복구하세요.
  Steam 파일 검사는 추가 Pak을 자동으로 지우지 않을 수 있습니다.
- 문제 제보에는 빌드 ID, 패치 파일 SHA-256, 재현 순서·화면과
  KoreanPatch\logs의 관련 기록을 포함하세요.
