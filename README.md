# GODSOUL 한글 패치

Steam판 GODSOUL 1.94용 비공식 한글 패치입니다.

[**다운로드**](https://github.com/yoodong724/GodSoul-ko/releases/latest)

1. 게임을 종료하고 기존 한글 패치가 있으면 백업합니다.
2. ZIP을 풀고 `GodSoul-Windows_0_P.pak`을 게임 설치 폴더의 `GODSOUL/Content/Paks/`에 넣습니다. 원본 `GodSoul-Windows.pak`은 그대로 둡니다.
3. 게임 언어를 **일본어**로 설정합니다.

삭제하려면 추가한 패치 파일만 제거하세요. 일부 배경 글자는 원문으로 남아 있습니다.
