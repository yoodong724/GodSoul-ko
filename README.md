- **1.98** 휴대전화 대화 기록의 일반 이모지와 호시무·월영·린시 스티커 표시명 62개를 번역했습니다. 연속 이미지와 뒤따르는 텍스트를 조립하는 서식 2개를 유지했습니다.

긴 문구는 1602px 창에서 확인했습니다. 새 게임 음성 선택의 첫 한국어 말풍선은 확인했고, 다른 두 옵션과 음성 재생은 미확인입니다. 2장 5번 장면의 대사·음성, 호시무 외전 P6 연출, 일부 전투 카드의 수치와 버프는 미확인입니다.

별도 로그라이크 모드는 제작사가 향후 출시할 기능으로 안내했습니다. 1.98 공개판에서 해당 모드의 휴식·보상 선택 화면은 확인하지 못했습니다. [제작사 11월 27일 공지](https://store.steampowered.com/news/app/1213300/view/1850460852988106)

## 설치 방법

1. `godsoul-ko-26979880.zip`을 내려받습니다. 첨부 체크섬과 ZIP의 SHA-256을 비교할 수 있습니다.
2. 게임과 게임 파일을 바꿀 수 있는 프로그램을 종료합니다.
3. 이전 버전을 설치기로 설치했다면 이전 `KoreanPatch/restore.cmd`로 복구합니다. 이전 수동 설치본은 `GODSOUL/Content/Paks/GodSoul-Windows_0_P.pak`을 게임 폴더 밖으로 옮깁니다.
4. ZIP의 `KoreanPatch` 폴더를 `GodSoul.exe`가 있는 폴더에 복사합니다. `KoreanPatch/install.cmd`를 실행하고 안내에 따라 진행합니다.
5. 게임 설정에서 **일본어(일본어 슬롯)**를 고르고 게임을 완전히 종료한 뒤 다시 실행합니다. 이 슬롯이 패치의 한국어로 바뀝니다.

패치를 제거하려면 게임을 종료하고 `KoreanPatch/restore.cmd`를 실행합니다. 복구가 완료될 때까지 `backup`과 `state` 폴더를 보관하세요.

## 소스와 재현 범위

**이 저장소의 소스 파일만으로는 한글 패치를 재현할 수 없습니다.** 게임에서 추출한 자료, 번역 및 수정한 리소스는 저장소에서 배포하지 않습니다. 설치에 필요한 패치 데이터는 릴리스 ZIP에 들어 있습니다.

`runtime/windows/`에 Windows 설치·복구 런타임과 ZIP 조립기가, `project/packaging/`에 설치 명세와 ZIP에 들어가는 안내문이 있습니다. ZIP을 다시 조립하려면 Python 3.11 이상, 해당 빌드의 원본 게임, 검증된 `GodSoul-Windows_0_P.pak`이 필요합니다. 그 Pak을 만드는 작업에는 별도의 게임 리소스 입력과 Unreal Pak 도구가 필요합니다.
