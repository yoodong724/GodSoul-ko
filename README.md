# GODSOUL 한글 패치

**적용 대상** GODSOUL 1.98 · Steam 빌드 `26979880` · Windows 11

[패치 ZIP 다운로드](https://github.com/yoodong724/GodSoul-ko/releases/download/v2026.11.28-rc1/godsoul-ko-26979880-rc1.zip)

1. 게임을 종료합니다. 이전 설치본은 기존 `KoreanPatch/restore.cmd`로 복구합니다. 수동 설치본의 `GODSOUL/Content/Paks/GodSoul-Windows_0_P.pak`은 게임 폴더 밖으로 옮깁니다.
2. ZIP을 풀고 `KoreanPatch` 폴더를 `GodSoul.exe` 옆에 둡니다.
3. `KoreanPatch/install.cmd`를 실행하고 `Y`로 확인합니다.
4. 게임 설정에서 **일본어 슬롯(한국어)**을 선택하고 게임을 완전히 종료한 뒤 다시 실행합니다.

**제거** 게임을 종료하고 `KoreanPatch/restore.cmd`를 실행합니다.
